МИДИЯ — ФИНАЛЬНАЯ ХАКАТОННАЯ СБОРКА

Публичное название: «Мидия».
Смысловая расшифровка: «Многослойная интеллектуальная диагностическая интерпретация анализов».
Слоган: «Мы не автоматизируем эмпатию — мы освобождаем для неё место».

!EXTRA_MATERIALS!

Папка EXTRA_MATERIALS содержит материалы для быстрой проверки проекта без необходимости запускать проект:

- presentation — презентация проекта;
- report_doctor_test — тестовый отчёт для врача;
- report_patient_test — тестовый отчёт для пациента;
- test_analysis — тестовые лабораторные данные для демонстрации;
- demonstration_of_work — наглядная демонстрация работы сервиса.

БЫСТРЫЙ ЗАПУСК WINDOWS

1. Распакуйте ZIP в обычную папку.
2. Откройте PowerShell в корне проекта.
3. Выполните:

   .\scripts\start_windows.bat

4. Откройте http://127.0.0.1:8501

КАК РАБОТАТЬ

- Укажите ФИО для текущего PDF, возраст и пол.
- Заполните жалобы / симптомы, анамнез и препараты.
- Загрузите один лабораторный файл или внесите анализы вручную.
- После загрузки обязательно проверьте распознанные значения и единицы.
- Нажмите «Выполнить скрининг».
- Просмотрите слои результата и при необходимости сформируйте локальное AI-пояснение.
- Скачайте врачебный PDF и/или лист пациента.

AI-пояснение опционально и формируется на русском языке. Основной скрининг работает без Ollama.
ФИО не передаётся в ML или LLM. Локальная база подтверждённых случаев обезличена.

API: .\scripts\start_api_windows.bat
Тесты: .\scripts\run_tests_windows.bat

DOCKER
