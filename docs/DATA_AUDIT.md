## Контракт кейса

В финальной версии три первичных материала организатора рассматриваются как единый контракт:

- `spec/Кейс_СУ.pdf` — постановка задачи;
- `data/deficiency_anemia.csv` — обучающая матрица;
- `spec/variables.xlsx` — словарь переменных и исходных единиц.

Словарь `variables.xlsx` содержит 48 переменных, и их имена и порядок полностью совпадают с 48 колонками CSV. Машиночитаемый снимок словаря находится в `knowledge/variables.json`.

## Пропуски как часть задачи

Пропуски не заменяются нормой. Это важно и для клинического слоя, и для карты неопределённости. Наиболее разреженные лабораторные переменные:

| Признак | Пропуски |
| copper | 85.2% |
| ceruloplasmin | 84.4% |
| vitamin_B6 | 83.9% |
| Ret_He | 73.1% |
| sTfR | 70.0% |
| active_B12 | 70.0% |
| MMA | 67.6% |
| homocysteine | 64.5% |
| LDH | 61.3% |
| indirect_bilirubin | 61.3% |
| haptoglobin | 58.8% |

Именно поэтому продукт не пытается показать врачу длинный список «недостающих анализов»: слой Value of Information ранжирует их по полезности для различения текущих ведущих гипотез.

## Разделение ролей данных

Симптомы, жалобы, анамнез, лекарства и история визитов имеют собственный клинический слой. Они не подмешиваются в обученный классификатор, потому что этих полей нет в предоставленной обучающей матрице. Это предотвращает скрытый train/serve mismatch.

Локальная история подтверждённых врачом наблюдений также не смешивается с исходным датасетом организатора: интерфейс явно показывает отдельно `reference cohort` и `local confirmed cases`.

## Техническая оценка модели

OOF-оценка выполнялась только для технической проверки прототипа с `StratifiedGroupKFold`, причём повторяющиеся `patient_id` и идентичные лабораторные профили удерживаются в одной группе.

Текущие OOF-метрики:

- accuracy: 0.889;
- balanced accuracy: 0.878;
- macro F1: 0.885;
- multiclass Brier score: 0.265;
- ECE top-score, 10 bins: 0.262.

Высокий ECE — важное ограничение. Поэтому `predict_proba` в продукте называется model score, а не клинической вероятностью диагноза. Эти цифры не являются внешней или клинической валидацией и не должны интерпретироваться как доказанная эффективность на реальной популяции.
