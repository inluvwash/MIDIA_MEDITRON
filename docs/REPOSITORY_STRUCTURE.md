# Структура репозитория

| Путь | Назначение |
| `HealthScreening.py` | основной Streamlit-интерфейс |
| `api.py` | FastAPI-интерфейс |
| `screening/` | клинические правила, ML, uncertainty, causal, отчёты, RAG |
| `tests/` | автоматические тесты |
| `data/` | исходный обезличенный датасет кейса |
| `models/` | обученная модель, метрики и model metadata |
| `knowledge/` | словари переменных, источники, нормализация |
| `examples/` | демо-входы и примеры результатов/PDF |
| `spec/` | исходное ТЗ кейса и `variables.xlsx` |
| `config/` | примеры переменных окружения |
| `scripts/` | Windows-скрипты запуска и тестирования |
| `docs/` | техническая, медицинская и проектная документация |
| `Dockerfile`, `docker-compose.yml` | воспроизводимый контейнерный запуск |

`books/` намеренно поставляется пустой: пользователь может добавить локальные разрешённые PDF для RAG; медицинское ядро от этого не зависит.
