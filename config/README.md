# Конфигурация

Конфигурационные параметры вынесены из кода в переменные окружения.

- `OLLAMA_URL` — адрес локального Ollama; AI-слой опционален.
- `OLLAMA_MODEL` — имя локальной модели.
- `HEALTHSCREENING_API_KEY` — опциональный ключ доступа к FastAPI (заголовок `X-API-Key`).
- `LOCAL_CASES_PATH` — путь к локальной обезличенной базе подтверждённых случаев.

Пример значений находится в `.env.example`.

## Как применяется

- **Локальный запуск (без Docker):** скопируйте `.env.example` в `config/.env`. Файл читает
  `screening/config.py`; уже заданные переменные окружения имеют приоритет.
- **Docker:** скопируйте `.env.example` в `.env` в корне проекта — `docker compose` подставит
  значения в `docker-compose.yml`. Без файла действуют значения по умолчанию.
- Без любого файла проект запускается с настройками по умолчанию.

Файлы с реальными секретами в репозиторий добавлять не нужно (`config/.env` и `.env` исключены
через `.gitignore` и `.dockerignore`).
