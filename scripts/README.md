# Скрипты запуска

- `start_windows.bat` — создаёт `.venv`, устанавливает зависимости и запускает Streamlit.
- `start_api_windows.bat` — то же для FastAPI.
- `run_tests_windows.bat` — устанавливает dev-зависимости и запускает pytest.

Скрипты запускаются из корня проекта, например: `.\scripts\start_windows.bat`.
